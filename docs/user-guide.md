# Orbitarium — User Guide

> Web-based real-position solar system simulator (Work 12 user docs).

## Getting Started

1. Visit the deployed site (`https://<your-org>.github.io/orbitarium/`) or run locally:
   ```bash
   pnpm install
   pnpm dev
   ```
2. **The main app `/` is the integrated solar system view** — Sun + 9 planets + Earth's Moon with real DE440 positions, Hipparcos starfield, IAU rotation, all orbit ellipses.
3. The dev catalog (`/dev/index`) lists 11 dev pages — each one demonstrates a single Work's slice in isolation (handy for debugging).

## Main App `/` — Controls

| Control | Action |
| --- | --- |
| **Drag** in the canvas | Orbit camera around the focused target (or SSB origin) |
| **Mouse wheel** | Zoom in/out |
| **Body chip (bottom)** | Click to focus the camera on a body. "System" returns to overview. |
| **▶ / ⏸** (top-right) | Play / pause the simulation clock. |
| **Rate select** (top-right) | 1s/s · 1m/s · 1h/s · 1d/s · 30d/s · 1y/s — how much simulated time passes per real second. |
| **URL fragment** | The current view (jdTdb + focused body) is encoded into the URL hash; copy/paste to share. |

## Share URL

Append `#?v=1&jd=<jdTdb>&body=<slug>&cam=<mode>` to the URL to restore a saved
view. The `share` module (`src/share/encode.ts`) exposes the encode/decode
helpers used by the main app.

## Time Presets

J2000 epoch, Voyager 1 launch (1977-09-05), 2024-04-08 total eclipse, 2026-05-06
demo. Click a preset on `/dev/time` to jump.

## Body Catalog

20 entries (Sun + 8 planets + Pluto + Earth's Moon + 4 Galilean + 5 Saturn
major). Charon (NAIF 901) is deferred — see [`bodies-conventions.md`](architecture/bodies-conventions.md).

## Camera Modes

- **free-fly** — direct position / lookAt control.
- **focus** — orbit around a body.
- **follow** — track a moving body (camera moves with it).
- **pov** — view from the body surface looking outward.

Presets: ecliptic top / Sun POV / Earth focus / Voyager 1 vantage.

## Performance

Bloom postprocess is opt-in (off by default). Toggle on `/dev/perf` and watch
the FPS / draw-call overlay. Frame budget target is 60 fps on a desktop GPU
with the default scene; Tycho-2 starfield + atmospheric scattering are
deferred to keep the baseline cheap.

## Troubleshooting

- **Blank canvas**: ensure WebGL 2 is supported (most modern browsers since 2018).
- **Stars don't load**: `public/data/starfield/hipparcos-vmag6.bin` must be present
  (generated by `pnpm starfield:preprocess`).
- **DE440 fetch fails**: precompute with `pnpm de440:preprocess` first.
- **Texture missing**: bodies fall back to a flat color (`fallbackColor` field).
  Add Solar System Scope textures per
  [`public/data/textures/README.md`](../public/data/textures/README.md).
