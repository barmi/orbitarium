### WebStorm에서 Orbitarium 프로젝트 실행 방법

이 프로젝트는 **Vite**와 **pnpm**을 기반으로 하는 React 프로젝트입니다. WebStorm에서 가장 효율적으로 실행하고 개발하는 방법들을 안내해 드립니다.

#### 1. `package.json`을 통한 빠른 실행 (가장 추천하는 방법)
1. WebStorm의 **Project** 패널에서 `package.json` 파일을 엽니다.
2. `scripts` 항목 안에 있는 `"dev": "vite"` 줄 왼쪽의 **초록색 실행 버튼(▶️)**을 클릭합니다.
3. **'Run dev'**를 선택하면 하단 **Run** 탭에서 개발 서버가 시작됩니다.
   - *팁: `package.json` 파일을 마우스 오른쪽 버튼으로 클릭하고 **'Show npm Scripts'**를 선택하면 별도의 도구 창에서 모든 스크립트를 관리할 수 있어 편리합니다.*

#### 2. 터미널을 이용한 실행
1. WebStorm 하단의 **Terminal** 탭을 엽니다 (단축키: `Alt + F12`).
2. 프로젝트 의존성이 설치되지 않았다면 먼저 설치합니다:
   ```bash
   pnpm install
   ```
3. 다음 명령어로 개발 서버를 실행합니다:
   ```bash
   pnpm dev
   ```
4. 터미널에 출력된 `http://localhost:5173` 링크를 `Command(⌘) + 클릭`하여 브라우저에서 확인합니다.

#### 3. 실행/디버그 구성(Run Configuration) 저장하기
나중에 버튼 하나로 바로 실행하고 싶다면 구성을 저장해두는 것이 좋습니다.
1. 우측 상단의 **'Add Configuration...'** 버튼을 클릭합니다.
2. 왼쪽 상단의 **'+'** 버튼을 누르고 **'npm'**을 선택합니다.
3. 다음과 같이 설정 정보를 입력합니다:
   - **Command**: `run`
   - **Scripts**: `dev`
   - **Package manager**: `pnpm` (기본값으로 자동 설정되나 확인 필요)
4. **OK**를 눌러 저장합니다. 이제 상단 도구 모음의 **재생 버튼(▶️)**만 누르면 언제든 서버를 켤 수 있습니다.

#### 주요 참고 사항
- **Node.js**: 프로젝트 설정에 따라 **Node.js v20.0.0 이상**이 설치되어 있어야 합니다.
- **포트**: 기본 포트는 **5173**입니다. 만약 이미 사용 중이라면 Vite가 자동으로 다른 포트(5174 등)를 할당하므로 터미널 로그를 확인하세요.
